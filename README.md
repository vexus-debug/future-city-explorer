# Future City Browser

I want to create a mobile web game, but first recreate the Future CITY 5.5 sci-fi city for the web version—featuring its futuristic skyline, the giant pyramid, elevated neon highways, and towers—optimized for mobile web with responsive touch exploration controls. We will proceed from there.
